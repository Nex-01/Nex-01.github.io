Cybersecurity Home Lab

I'm building a comprehensive cybersecurity lab environment as part of my journey toward deeper security expertise. This lab is designed to support hands-on learning across network security, threat detection, vulnerability assessment, and penetration testing, aligned with NIST frameworks and real-world attack scenarios.

Phase 1: Foundation (In Progress)

  • pfSense Firewall: Network segmentation, firewall rules, VLANs
  • Active Directory: Domain setup, group policy, security hardening
  • Windows Server: Test environment for domain services

Current focus: Network topology and AD foundation

Phase 2: Detection & Response

  • ELK Stack: Elasticsearch, Logstash, Kibana for SIEM
  • Log aggregation: Centralized logging from all components
  • Threat monitoring: Real-time alerting and analysis

Planned: After foundation is stable

Phase 3: Offensive Security

  • Kali Linux: Penetration testing toolkit
  • OpenVAS: Vulnerability scanning and assessment
  • DVWA: Deliberately Vulnerable Web Application for practice

Planned: After detection layer is operational

Progress updates: As each component reaches completion, I'll add detailed writeups, architecture diagrams, and links to standalone documentation here. Check back to see the lab evolve.
